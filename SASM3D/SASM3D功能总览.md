# SASM3D 功能总览

**SASM3D** 是一个基于 FreeCAD 的专业3D发光字(Channel Letters)建模软件。

安装路径: `D:\Program Files (x86)\SASM3D\`

---

## 一、基础FreeCAD 模块 (Workbenches)

| 模块 | 功能 |
|------|------|
| **Part** | 零件建模 - 基础形状、布尔运算、复合工具 |
| **PartDesign** | 零件设计 - 齿轮、链轮生成 |
| **Sketcher** | 草图绘制 - 2D轮廓绘制 |
| **Draft** | 绘图 - 2D绘图工具 |
| **Mesh** | 网格处理 |
| **MeshPart** | 网格与零件转换 |
| **Surface** | 曲面建模 |
| **Spreadsheet** | 电子表格 |
| **OpenSCAD** | OpenSCAD集成 |
| **Import** | 文件导入 |
| **Material** | 材质管理 |
| **Measure** | 测量工具 |

---

## 二、SASM3D 专属功能

### 1. 输入方式
- **文本输入** - 输入文字直接生成发光字轮廓
- **文件导入** - 支持 CDR、DXF、EPS、SVG 格式

### 2. 工艺类型(14种)

| 工艺 | 名称 | 说明 |
|------|------|------|
| PROC_1 | 平面+正光 | 壁和底部一体 |
| PROC_2 | 平面+正背光 | 壁和底部分离 |
| PROC_3 | 斜边+正光 | 外壳嵌入内壳 |
| PROC_4 | 斜边+正背光 | 壁和底部分离 |
| PROC_5 | 斜面+正光 | 壁和底部分离 |
| PROC_6 | 斜面+正背光 | 壁和底部分离 |
| PROC_7 | 圆角+正光 | 实心一体 |
| PROC_8 | 圆角+正背光 | - |
| PROC_9 | 斜面实心墙 | - |
| PROC_10 | 斜面曲面墙实心 | - |
| PROC_11 | 圆弧曲面实心 | - |
| PROC_12 | 锥形实心 | - |
| PROC_13 | 管状实心 | - |
| PROC_14 | DIY自定义 | 用户自定义工艺 |

### 3. 参数设置

#### 顶部(Top) 参数
- 台阶高度: 2.0-5.0mm (亚克力板厚度)
- 台阶宽度: 0.4-1.2mm

#### 墙体 (Wall) 参数
- 整体墙高: 25.0-80.0mm
- 墙厚: 1.2-3.2mm
- 斜边角度: 45.0-85°
- 斜边基座高度: 10.0-75.0mm

#### 底部 (Bottom) 参数
- 底边高度: 2.0-5.0mm
- 凹槽高度: 2.0-10.0mm
- 凸台宽度: 默认0.8mm

### 4. 对象操作工具

| 功能 | 快捷键/说明 |
|------|------|
| **撤销/重做** | 操作历史管理 |
| **缩放** | 选中对象后按 i/o 键放大/缩小 |
| **移动** | 方向键移动X/Y，u/d键移动Z轴 |
| **旋转** | 按住x/y/z键+方向键绕轴旋转 |
| **删除** | 删除选中对象 |
| **布尔运算** | 并集、交集、差集 |
| **合并** | 组合多个对象为组 |
| **拆分** | 将组拆分为独立对象 |
| **镜像** | 沿XY/YZ/XZ平面镜像 |
| **缩放比例** | 按比例或按轴独立拉伸 |
| **连桥** | 在两个对象底部创建连接桥 |
| **打孔** | 在对象上打圆形或六边形孔 |

### 5. 导出功能
- **导出 STL** - 用于3D打印
- **导出 PLT** - 用于激光切割亚克力板
- **路径偏移补偿** - 控制PLT路径的内/外偏移量

### 6. 高级功能
- **轮廓偏移** - 文字/图形轮廓向内/外偏移
- **孔洞识别** - 自动识别闭合区域中的孔洞
- **Wire分析** - 曲线分析与处理
- **SVG预检** - 导入前检查SVG文件
- **STL加密** - STL文件加密保护

## 四、核心源代码文件

SASM3D 专属代码位于: `D:\Program Files (x86)\SASM3D\data\Gui\Resources\`

| 文件 | 功能 |
|------|------|
| `sidewindow.py` | 主侧边栏窗口，包含所有参数控件 |
| `process_config.py` | 工艺类型配置管理 |
| `horizontal_operations.py` | 水平操作（移动、缩放、旋转等） |
| `vertical_operations.py` | 垂直操作（布尔、合并、拆分、打孔等） |
| `SASMOffsetFromText.py` | 文字轮廓偏移 |
| `sasm_create_base_component.py` | 基础组件创建 |
| `sasm_create_pad.py` | 拉伸创建 |
| `sasm_create_sweep_psolid0716.py` | 扫掠实体创建 |
| `SASM_STLEncryptor.py` | STL加密 |
| `tool_tips.py` | 工具提示文本 |
| `dxf_export_svg.py` | DXF导出SVG |
| `svg_pre_check.py` | SVG预检查 |
| `wire_to_sketch_wire.py` | Wire转草图 |
| `hole_identify.py` | 孔洞识别 |
| `simple_offset.py` | 简单偏移 |
