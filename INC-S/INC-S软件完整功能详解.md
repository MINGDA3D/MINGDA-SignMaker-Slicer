# INC-S 软件完整功能详解

---

## 第一部分：软件安装与文件准备

### 安装步骤
1. 将真材INC软件压缩包保存在D盘或F盘
2. 解压到当前文件夹
3. 找到"真材INC-S"应用程序图标，右键发送到桌面快捷方式

### 从CorelDRAW导出DXF文件
- 使用CDR X4版本
- 导出时勾选"只是选定的"
- **导出版本**：AutoCAD 2004
- **导出单位**：必须是毫米
- **导出文本方式**：选择曲线

### 颜色标识规范（在CDR中使用RGB调色板）
| 颜色 | 用途 |
|------|------|
| RGB青色 | 连襟框 |
| RGB绿色 | 底孔 |
| RGB蓝色 | 面板花纹 |

## 第三部分：操作流程详解

### 第一步：导入与基础设置

#### 1. 选择机器台面大小
- 根据实际机器设置宽度和高度（单位mm）

#### 2. 导入DXF文件
- 将文件内容拉到机器版面以内
- 框选内容
- 点击"打散"
- 再单个字"组合"

#### 3. 起始点编辑
- 选中字后点"起始点编辑"
- 将起点设置在尖角或内角处
- 设置完成后按键盘ESC键退出
- 绿色点表示起始点位置

#### 4. 镜像处理
- 如需镜像可提前在CDR或INC软件中进行镜像操作

#### 5. 排版设置（多个字时）

**自动排版：**
- 可选择"整版打印"与"单个打印"
- 建议选择单个打印
- 如字壳小于10公分可将两个字结合在一起打印
- 设置横轴边界、纵轴边界
- 设置X图形间隙、Y图形间隙

**手动排版：**
- 点"打印顺序编辑"
- 将字选中就会有顺序号
- 鼠标左键是加，右键是减
- 每个字都需要单独设置
- 设置完成后按键盘ESC键退出

**重要：以上设置完成后需全选机器版面上所有的字**

### 选项卡一：字壳工艺

#### 异形边选择
| 按钮 | 功能 |
|------|------|
| 添加 | 可添加用户画好的异形边 |

| 删除 | 可删除画好的或软件本身带有的异形边 |

#### 字壳工艺基本设置
| 参数 | 说明 | 建议值 |
|------|------|--------|
| 镜像打印/正常打印 | 文件没有镜像过选正常打印，文件镜像过选镜像打印 | 根据实际情况 |
| 字边类型 | 直边、斜边、异形边三个选项 | 根据工艺需求 |
| 字壳高度 | 字壳总高度 | 根据实际需求（单位mm） |
| 斜边宽度 | 斜边倾斜的宽度（直边字无需设置） | 一般设置5 |
| 面板厚度 | 适合做斜边正扣亚克力字，设置亚克力板实际厚度（直边字无需设置） | 亚克力板实际厚度 |
| 底板厚度 | 做斜边字底部预留的直边高度（直边字无需设置） | 一般设置10 |
| 层高 | 打印每一层的高度 | 一般设置0.3 |
| 预打边线偏移 | 字壳与外围安全线的距离 | 一般在15-35之间 |
| 预打边线次数 | 外围安全线的次数；如打印面板一体成型需要设置2-4次 | 一般设置1次 |
| 雕刻刀刃宽 | 雕刻亚克力板用的刀具大小 | 无需更改 |
| 壁厚 | 字壳边带的厚度 | 40cm以下的字设置1.2mm，40cm以上的字设置1.3mm |
| 壁厚补偿 | 壁厚补偿值 | 默认设置0，无需补偿 |
| 走线次数 | 打印壁厚的次数；如需打印2.4mm壁厚将走线次数设置2 | 默认打印1次 |
| 走线高度 | 在走线次数为2的前提下可设置字壳最里面壁厚的高度；设置0为两层壁厚高度一致 | 根据需求 |
| 走线偏移 | 在走线次数为2的前提下观察两层壁厚是否粘接完好，如出现两层之间有缝隙需减少此值，反之加大 | 默认设置0.8 |
| 字芯高度 | 可独立设置字内孔的高度 | 一般默认为0 |
| 字芯斜边宽度 | 可改变字内孔打印直边或斜边（设置0为直边，数值越大内孔偏移越大） | 根据需求 |

### 选项卡三：台阶V槽

#### 台阶设置说明
- 可设置多个台阶，需要几个就勾选几个
- 一般勾选2个台阶
- **台阶1**：底部位置，假设PVC底板3毫米，台阶1位置设置4（多预留1至2毫米）
- **台阶2**：靠近发光面位置，假设3公分高的字面贴3毫米亚克力板或者灌3毫米液态亚克力胶水，台阶2位置设置27（用字的总高度减去亚克力板实际厚度）

#### 台阶参数（台阶1-7有效）
| 参数 | 说明 | 建议值 |
|------|------|--------|
| 位置 | 预留台阶的位置（单位mm） | 根据底板/面板厚度计算 |
| 高度 | 台阶的厚度（设置1.2是V型台阶，设置为0是平的台阶） | V型设1.2，平台阶设0 |
| 宽度 | 台阶宽度 | 1.2 |

#### 台阶打印参数
| 参数 | 说明 | 建议值 |
|------|------|--------|
| 台阶速度 | 打印台阶时的速度 | 根据需求 |
| 喷头水平偏移 | 打印台阶时喷头离字壳距离 | 根据需求 |
| 喷头吐丝宽度 | 打印台阶时喷嘴挤出的宽度 | 根据需求 |
| 台阶厚度 | 做平的台阶设置为0.3打印一层 | 0.3 |

### 选项卡五：连襟字

#### 连襟字有效
- 如果需要制作连襟字需要勾选此项

#### 连襟类型
| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 三角形连襟 | 三角形连襟方式 | 常规使用 |
| 菱形连襟 | 菱形连襟方式 | 制作双面发光连襟字 |

#### 连襟参数
| 参数 | 说明 | 建议值 |
|------|------|--------|
| 连襟宽度 | 在CDR软件画好连襟框的宽度数值设定在此行（根据字壳笔画宽度设置） | 一般设置10、15、20 |
| 连襟高度 | 连襟顶部斜边的高度 | 5 |
| 连襟底座高度 | 连襟底部直边的高度 | 5 |
| 连襟支撑偏移 | 镜像打印连襟字软件会自动生成连襟支撑与字壳边缘距离 | 默认2.5 |
| 整板排序行距 | 整板排序行距 | 默认设置为0 |

#### 连襟高度计算说明
- **连襟高度 + 连襟底座高度 = 连襟的总高度**
- 假如使用菱形连襟，需要将连襟高度设大，连襟底座高度会变为支撑的高度
- **举例**：字壳3公分高度使用菱形连襟高度为2公分，则连襟高度设置20，连襟底座高度为5，这样中间连襟高度为2公分，上下各留5毫米空位

| 角度 | 打印网格角度 | 默认用45度 |

## 第五部分：文件输出

### 加工参数
| 参数 | 说明 | 建议值 |

| 打印速度 | 打印过程的速度 | 字体复杂、10cm至30cm尖角较多的小字：30-40mm/s；字体较大、30cm至60cm笔画简单的大字：50-80mm/s |

| 参数 | 说明 | 建议值 |
|------|------|--------|

### 缺料补偿参数（1号、2号、3号挤出机分别设置）
| 参数 | 说明 | 建议值 |
|------|------|--------|
| 近距离缺料补偿 | 喷头近距离跳动起始点补料的长度 | 0.4 |
| 远距离缺料补偿 | 喷头远距离跳动起始点补偿的长度 | 0.4 |
| 远近距离分界线 | 利用空走距离判断远距离与近距离 | 100 |

**设定远近距离缺料补偿范围在0-0.6之间**
- 数值过大会导致起始点位置变大
- 设置过小导致起点位置缺料
- 跳动远数值加大，跳动近数值减小

## 第七部分：三维预览

### 打开三维预览软件
1. 在INC软件主界面点击"三维预览"按钮
2. 或直接打开"真材科技切片软件4.10.0"

### 打开Gcode文件
1. 文件 → 打开文件（Ctrl+O）
2. 选择保存好的Gcode格式文件
3. 点击"打开"

### 颜色显示设置
如果没有显示文件颜色：
1. 点击"颜色方案" → "材料颜色"
2. 将"空驶"勾选后就能显示

### 颜色方案选项
| 选项 | 说明 |
|------|------|

| 打印辅助结构 | 辅助结构显示 |

| 填充 | 填充显示 |
| 开始 | 开始点显示 |

### 预览操作
- 显示正常后可拖动软件下方横条查看打印进度与机器实际行走状态
- 确保参数设置没有问题

## 第八部分：文件传输与打印

### U盘传输
1. 三维预览确保参数设置没有问题后
2. 将Gcode格式文件拷贝到U盘
3. 右键文件 → 发送到 → U盘
4. 将U盘插在机器上打印

### WiFi传输
1. 在INC软件主界面点击"WiFi传输"
2. 使用WiFi传输软件将做好的文件通过软件发送到机器打印
