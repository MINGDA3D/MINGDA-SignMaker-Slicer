# SignMaker Slicer 功能需求清单

> 基于 INC-S 软件完整功能分析

---

## 一、文件操作模块

### 1.1 文件格式支持
| 功能 | 说明 | 优先级 |
|------|------|--------|
| 打开DXF文件 | 支持AutoCAD 2004格式DXF | 高 |
| 打开DADA文件 | 软件专用项目格式（可选） | 低 |
| 保存DADA文件 | 保存页面所有内容与参数 | 低 |
| 导入DXF | 向现有项目追加DXF内容 | 中 |
| 导出DXF | 导出编辑后的轮廓 | 中 |
| 输出G-code | 生成打印文件(.gcode) | 高 |

### 1.2 DXF解析要求
| 功能 | 说明 | 优先级 |
|------|------|--------|
| 解析多段线(POLYLINE/LWPOLYLINE) | 提取闭合轮廓 | 高 |
| 解析样条曲线(SPLINE) | 转换为多段线 | 中 |
| 解析圆弧(ARC) | 转换为多段线 | 中 |
| 解析椭圆(ELLIPSE) | 转换为多段线 | 低 |
| 颜色识别 | RGB青色=连襟框, RGB绿色=底孔, RGB蓝色=面板花纹 | 高 |
| 单位处理 | 支持毫米单位 | 高 |
