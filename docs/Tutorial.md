# MINGDA SignMaker 海外用户教学大纲（当前功能完整版）

> 适用对象：面向海外用户的视频课程、软件培训、售后教学与代理商培训。
>
> 编写原则：按照“课本目录”的方式组织课程，每章有明确主题、知识点和录制要求。课程以当前软件功能为准，旧版大纲只作为结构参考，不作为功能范围限制。

## 一、课程总体设计

### 1、课程目标

1、让海外用户理解 MINGDA SignMaker 的用途：把 DXF、SVG 或文字图形转换为发光字 3D 打印生产文件。
2、让用户掌握从导入图形、设置工艺、处理切片、预览检查到导出 G-code/STL/DXF 的完整流程。
3、让用户能够根据不同打印机、材料、字壳结构、亚克力面板和背板需求调整参数。
4、让用户理解常见错误的原因，并能通过 2D 视图、3D 预览和参数检查自行排查。
5、让代理商或售后人员能够按照统一话术录制海外教学视频。

### 2、建议课程规模

本课程建议编为 25 章，共 185 个知识点。章节数量不压缩，目的是让每个功能点都能单独录制、单独复用。

1、海外版课程建议使用英文界面录制，必要时在字幕中补充中文术语。
2、每章只讲一个主任务，避免在同一视频里混讲多个流程。
3、每个参数都要说明三个内容：参数在哪里、参数控制什么、错误设置会造成什么结果。
4、关键章节必须包含“正确示范”和“错误示范”，例如导入错误尺寸、未处理直接导出、超出打印区域、槽位互斥等。
5、每章结尾用 10 到 20 秒回顾本章完成了什么，并提示下一章要做什么。

# 第一章 软件定位与生产闭环（5 个知识点）

## 学习目标

让用户先理解软件解决什么问题，以及最终会输出哪些生产文件。

## 知识点

1、MINGDA SignMaker 的定位：发光字、字壳、亚克力面板、背板相关的 3D 打印切片软件。
2、标准生产流程：准备图形文件、新建项目、导入图形、设置工艺参数、Process 处理、3D Preview 检查、导出生产文件。
3、主要输入文件：DXF、SVG、项目文件 SMP。
4、主要输出文件：G-code、STL、Back Plate DXF、Acrylic Face DXF。
5、软件与普通 3D 打印切片软件的区别：它重点处理字壳高度、边型、槽位、防翘、换色、背板和亚克力面板补偿。

## 录制方法

1、先展示一个完整案例的最终 3D 预览。
2、再展示导出的 G-code 和 DXF 文件。
3、不要一开始讲参数细节，只讲“从图形到生产文件”的闭环。

# 第二章 录制准备与示例文件（6 个知识点）

## 学习目标

统一课程中使用的文件、打印机、单位和界面语言，保证后续视频连贯。

## 知识点

1、准备一个简单英文单词 DXF，例如 LOGO、OPEN、BAR。
2、准备一个带内孔的字母文件，例如 A、R、O，用于讲内孔、槽位、底面和补偿。
3、准备一个 SVG 文件，用于说明 SVG 也可以导入。
4、准备一个复杂商标文件，用于讲组合、分解、打印顺序和导出检查。
5、统一单位为毫米，强调导入图形尺寸要与实际生产尺寸一致。
6、选择一个固定打印机配置作为主线，例如 MINGDA AD-F4 Pro 0.6 Nozzle。

## 录制方法

1、课程开始前建立一个专用文件夹，例如 `SignMaker Tutorial Files`。
2、所有示例文件放在同一目录，便于演示 Open Recent 和 Recent Projects。
3、第一套课程不要频繁更换机器型号，避免用户混淆。

# 第三章 界面总览（7 个知识点）

## 学习目标

让用户建立软件界面的整体地图，知道每个区域负责什么。

## 知识点

1、Home 页面：用于新建项目、打开项目和查看 Recent Projects。
2、Project 页面：用于 2D 编辑、参数设置和处理切片。
3、Preview 页面：用于查看 3D 结果和检查层。
4、顶部标题栏：包含 Menu、Project、Preview、Process、Export 等入口。
5、左侧 Shape List：管理导入的图形对象和生成的文字对象。
6、中间 2D Canvas：显示平台、网格、图形轮廓、选择状态和编辑结果。
7、右侧参数面板：包含 Shape、Machine、Print 三类主要参数。

## 录制方法

1、先用鼠标依次指向每个区域，不进入参数细节。
2、用一句话说明每个区域的作用。
3、最后切换一次 Project 和 Preview，让用户知道两者关系。

# 第四章 标题栏菜单、语言、主题与最近文件（8 个知识点）

## 学习目标

补齐旧大纲缺失的标题栏功能，让用户掌握软件全局入口。

## 知识点

1、Menu 菜单入口：包含文件、导出、语言、主题、教程、更新、关于和退出。
2、Language 语言切换：演示切换到 English，并说明海外课程建议使用英文界面。
3、Theme 主题切换：System、Dark、Light 三种模式。
4、主题跟随系统：选择 System 后，软件会根据操作系统主题显示。
5、Open Recent：可以打开最近使用的 DXF、SVG、SMP 文件。
6、Recent Projects：Home 页面只显示项目类文件，重点用于快速打开 SMP 项目。
7、Show Configuration Folder：打开配置目录，用于售后排查配置、打印机资料和日志相关问题。
8、Tutorial、Check for Updates、About：分别用于打开教程、检查更新和查看软件信息。

## 录制方法

1、先切换语言，再切换主题，录制时明确说明这两个设置会保存。
2、打开一个 DXF 和一个 SMP，然后返回 Home 展示 Recent Projects 与 Open Recent 的区别。
3、主题切换不要只口述，必须实际切换 Dark 和 Light 让用户看见变化。

# 第五章 新建、打开、保存与项目复用（8 个知识点）

## 学习目标

让用户理解文件和项目的区别，避免把 DXF 当成工程文件使用。

## 知识点

1、New Project：清空当前工作区，开始一个新任务。
2、Open File：打开 DXF 或 SVG 图形文件。
3、Open Project：打开 SMP 项目文件。
4、Save Project：保存当前项目，包含图形和参数。
5、Save As：另存为新的 SMP 项目文件。
6、SMP 项目的用途：复用客户订单、保存参数、继续编辑。
7、DXF/SVG 与 SMP 的区别：DXF/SVG 是图形输入，SMP 是软件项目。
8、未保存项目的风险：关闭软件或新建项目前要先保存。

## 录制方法

1、用同一个示例文件先导入 DXF，再保存为 SMP。
2、关闭或新建项目后，再打开 SMP，证明参数和图形可以恢复。
3、不要把导出 G-code 与保存项目混在一起讲，二者是不同动作。

# 第六章 导入 DXF、SVG 与文字生成（7 个知识点）

## 学习目标

让用户掌握图形来源，并知道导入后第一时间应该检查什么。

## 知识点

1、导入 DXF：适合 CAD、CorelDRAW、Illustrator 导出的轮廓文件。
2、导入 SVG：适合矢量图形、Logo 和网页矢量文件。
3、导入后检查尺寸：确认宽度、高度是否符合实际生产尺寸。
4、导入后检查位置：确认图形是否在打印区域内。
5、导入后检查轮廓：确认外轮廓、内孔和断线是否正确。
6、Text 工具：直接在软件内生成文字对象。
7、文字对象的后续处理：生成后可像普通图形一样移动、缩放、设置工艺和处理。

## 录制方法

1、分别导入一个 DXF 和一个 SVG。
2、录制一个文字生成案例，例如输入 `OPEN`。
3、导入后立即放大检查内孔和轮廓，不要直接进入导出。

# 第七章 Project 页面与 2D 视图操作（7 个知识点）

## 学习目标

让用户熟练操作 2D 画布，为后续编辑和参数检查打基础。

## 知识点

1、鼠标滚轮缩放视图。
2、右键或中键拖动画布平移视图。
3、Fit to Window：让图形自动适配窗口。
4、Reset View：重置视图位置和缩放。
5、网格和打印平台：用于判断尺寸和位置。
6、打印区域边界：图形必须放在可打印范围内。
7、Bed Exclude Area：避让区域会显示在平台上，图形不要放入不可打印区域。

## 录制方法

1、导入一个较大的图形，故意缩放到看不全，再使用 Fit to Window。
2、展示打印区域和避让区域，说明它们来自 Machine 设置。
3、把本章作为操作基础，不讲复杂工艺。

# 第八章 Shape List 与图形对象管理（6 个知识点）

## 学习目标

让用户知道多对象项目中如何选择、管理和检查图形。

## 知识点

1、Shape List 显示当前项目中的图形对象。
2、点击列表对象可以选择对应图形。
3、多个图形对象可以分别设置、移动和处理。
4、选择对象后，2D 画布会显示选中状态。
5、复杂 Logo 建议先确认对象数量和轮廓结构。
6、删除对象前应确认是否已经保存项目。

## 录制方法

1、导入一个包含多个字母或多个图形的文件。
2、逐个点击 Shape List 中的对象，让用户看到画布变化。
3、强调对象管理是打印顺序、组合和分解的基础。

# 第九章 基础编辑：移动、旋转、缩放、镜像（8 个知识点）

## 学习目标

让用户掌握最常用的几何编辑功能。

## 知识点

1、Move 工具：拖动对象改变位置。
2、Rotate 工具：旋转图形方向。
3、Scale 工具：等比例或非等比例缩放。
4、Mirror Horizontal：水平镜像。
5、Mirror Vertical：垂直镜像。
6、Transform 面板中的精确移动：输入 X、Y 数值。
7、Transform 面板中的精确旋转和缩放：输入角度、比例或目标尺寸。
8、Uniform Scale：锁定宽高比例，避免文字变形。

## 录制方法

1、先用鼠标操作，再用数值面板做精确调整。
2、演示方向键微调：普通方向键移动 1mm，Shift 加方向键移动 10mm。
3、演示错误案例：关闭 Uniform Scale 后文字被拉伸变形。

# 第十章 进阶编辑：布尔、组合、分解与撤销重做（8 个知识点）

## 学习目标

让用户掌握复杂图形整理能力，减少导入文件带来的问题。

## 知识点

1、Intersection：交集，用于保留两个图形重叠部分。
2、Difference：差集，用于从一个图形中减去另一个图形。
3、Group：组合多个对象，便于整体移动和处理。
4、Ungroup：取消组合，恢复单独对象编辑。
5、Explode Asset：分解资产或复合对象，便于单独处理。
6、Undo：撤销上一步操作。
7、Redo：恢复被撤销的操作。
8、复杂编辑前先保存项目，避免误操作造成返工。

## 录制方法

1、用两个简单矩形或字母演示 Intersection 和 Difference。
2、用多字母 Logo 演示 Group 和 Ungroup。
3、每个操作后都使用 Undo 和 Redo 演示可恢复性。

# 第十一章 起始点与打印顺序（6 个知识点）

## 学习目标

让用户理解起始点和打印顺序对喷嘴路径、接缝和生产稳定性的影响。

## 知识点

1、Start Point 工具：设置轮廓打印开始位置。
2、起始点影响接缝位置，建议放在不显眼或便于后处理的位置。
3、Print Order 工具：设置多个对象的打印顺序。
4、打印顺序影响空驶路径、拉丝风险和生产效率。
5、复杂 Logo 建议先设置顺序，再导出 G-code。
6、修改起始点或打印顺序后，需要重新 Process 才能检查结果。

## 录制方法

1、用带多个字母的项目演示 Print Order。
2、放大一个字母轮廓演示 Start Point。
3、说明这两个功能不是视觉装饰，而是会影响 G-code 路径。

# 第十二章 Shape 基础工艺参数（7 个知识点）

## 学习目标

让用户掌握 Shape 页签中最基础、最常用的切片参数。

## 知识点

1、Shape 页签包含 Wall、Bottom、Top、Other 四个子页。
2、Shell Height：字壳总高度。
3、Layer Height：层高，影响层数、表面质量和打印时间。
4、Line Width：线宽，通常与喷嘴直径和材料流量有关。
5、Wall Thickness：壁厚，影响强度、透光和打印时间。
6、Z 向高度参数会按层高网格向上对齐，避免出现非整层高度。
7、修改基础参数后，需要 Process 重新生成切片。

## 录制方法

1、用一组参数生成一次普通直边字壳。
2、改变 Shell Height 和 Layer Height，说明层数变化。
3、不要在本章同时讲斜边、槽位和换色，避免信息过载。

# 第十三章 Wall 边型：直边、斜边、异形边（8 个知识点）

## 学习目标

让用户掌握字壳侧壁造型，这是发光字软件的核心章节。

## 知识点

1、Straight Wall：直边，适合普通发光字字壳。
2、Beveled Wall：斜边，适合需要外观过渡或装配空间的字壳。
3、Bevel Direction：Top Small 和 Top Large 控制上口与下口大小关系。
4、Bevel Horizontal Width：斜边水平宽度。
5、Bottom Straight Height：底部直边高度，靠近底板侧。
6、Top Straight Height：顶部直边高度，靠近面板侧。
7、Custom Wall：异形边，可以选择预设模板。
8、Import DXF：导入自定义边型轮廓，用于特殊客户需求。

## 录制方法

1、同一个字母分别生成 Straight、Beveled、Custom 三种结果。
2、切换到 3D Preview 对比侧壁差异。
3、斜边章节必须展示 Top Small 与 Top Large 的区别。

---

# 第十四章 Top 顶部结构（6 个知识点）

## 学习目标

让用户理解顶部结构与面板安装方式的关系。

## 知识点

1、Top 页签用于设置字壳顶部和面板安装相关结构。
2、None：不生成顶部附加结构。
3、Top Shell：生成顶部封边或顶部壳体结构。
4、Top Shell Thickness：顶部壳体厚度。
5、Acrylic Face Slot：亚克力面板直槽。
6、Acrylic Face V-Groove：亚克力面板 V 槽，适合需要插入或定位面板的结构。

## 录制方法

1、先展示 None，再展示 Top Shell。
2、再切换 Acrylic Face Slot 和 Acrylic Face V-Groove。
3、强调 Top Shell 与面板槽类结构存在工艺互斥关系，不能当作普通叠加功能理解。

---

# 第十五章 Bottom 底部结构与螺丝孔（10 个知识点）

## 学习目标

让用户掌握底部结构、背板安装、灯带槽和螺丝孔相关功能。

## 知识点

1、Bottom 页签用于设置字壳底部、背板、灯带槽和包边结构。
2、None：不生成底部附加结构。
3、Bottom Shells：生成底面壳层或底部封闭结构。
4、Bottom Shell Thickness：底壳厚度。
5、Screw Hole 工具：在底壳结构中添加螺丝孔。
6、Bottom Screw Hole Diameter：螺丝孔直径。
7、Back Plate Slot：背板直槽，用于背板安装定位。
8、Back Plate V-Groove：背板 V 槽，用于特定装配方式。
9、LED Strip Slot：灯带槽，可设置外轮廓槽和内孔槽。
10、Bottom Edge Wrap 与 Bottom Outline：用于底部包边和底部勾边类结构。

## 录制方法

1、先讲 Bottom Shells 和 Screw Hole，因为这是海外用户最容易理解的应用。
2、再讲 Back Plate Slot、Back Plate V-Groove 和 LED Strip Slot。
3、特别说明某些底部结构互斥，打开一个结构时另一个结构可能会自动关闭。

# 第十六章 Other：防翘裙边、连筋桥、DXF 补偿（10 个知识点）

## 学习目标

让用户掌握提高打印稳定性、连接字形和导出板件补偿的功能。

## 知识点

1、Anti-Warp Brim：防翘裙边，用于降低边角翘起风险。
2、Brim Height：裙边高度。
3、Brim Speed：裙边打印速度。
4、Breakaway Gap：可拆间隙，用于控制裙边拆除难度。
5、Outer Brim 与 Inner Brim：外侧裙边和内孔裙边。
6、Letter Bridges：连筋桥，用于连接分散的字母或笔画。
7、Bridge Type：Triangle 和 Diamond 两种桥接形状。
8、Auto-Detect Bridge Points：自动检测可连接位置。
9、Bridge Width、Bridge Bevel Height、Bridge Base Height：控制桥的宽度、斜面高度和基础高度。
10、DXF Export Compensation：背板和亚克力面板 DXF 导出补偿，包括外轮廓间隙、内孔间隙和激光切缝。

## 录制方法

1、用一个容易翘边的大字母演示 Anti-Warp Brim。
2、用两个分离字母演示 Letter Bridges。
3、导出 DXF 前演示外轮廓补偿、内孔补偿和激光切缝的作用。

# 第十七章 Machine：打印机配置与硬件参数（10 个知识点）

## 学习目标

让用户学会选择或创建打印机配置，避免尺寸、喷嘴、退料和平台参数错误。

## 知识点

1、Machine 页签用于管理打印机和硬件相关参数。
2、Printer Profile：选择当前打印机配置。
3、内置 MINGDA 打印机配置：AD-F4 Mini、AD-F4、AD-F4 Pro、AD-F6 Pro、AD-F10 Ultra。
4、喷嘴规格配置：0.4、0.6、0.8 Nozzle。
5、New Printer Profile：新建自定义打印机配置。
6、Duplicate、Rename、Delete：复制、重命名和删除配置。
7、Printable Area X/Y/Z：打印区域尺寸。
8、Bed Exclude Area：平台避让区域。
9、Nozzle Diameter 与 Filament Diameter：喷嘴直径和耗材直径。
10、Retract Length、Retract Speed、Short Z-Hop、Long Z-Hop、Long Travel Threshold：回抽和 Z 抬升参数。

## 录制方法

1、先选择一个内置 MINGDA 机型作为主线配置。
2、再复制一个配置并改名为 Tutorial Custom。
3、演示修改打印区域后，2D 画布平台范围发生变化。

# 第十八章 Print：速度、温度与冷却（7 个知识点）

## 学习目标

让用户理解打印质量与速度、温度、冷却参数的关系。

## 知识点

1、Print 页签用于设置生产过程中的运动和材料参数。
2、外壁、内壁或普通路径速度会影响表面质量和打印时间。
3、槽位、台阶或细节结构速度不宜过高。
4、打印温度要结合材料和喷嘴规格设置。
5、冷却风扇设置会影响小结构成型和层间粘结。
6、参数过快可能造成缺料、拐角质量差或振纹。
7、参数过慢会增加生产时间，也可能造成局部过热。

## 录制方法

1、用默认参数作为推荐起点。
2、不要给所有材料固定唯一数值，应说明要根据材料品牌和机器状态微调。
3、通过预览和导出时间估计说明速度参数的影响。

# 第十九章 换色、Prime Tower 与起止 G-code（8 个知识点）

## 学习目标

让用户掌握多色或换料打印相关设置。

## 知识点

1、Enable Color Change：开启换色功能。
2、Change At Height：设置换色发生的高度。
3、Macro Index：选择换色宏，常用于不同打印机固件或多工具头流程。
4、初始颜色通常由 Start G-code 决定，换色点执行对应宏。
5、Prime Tower：换色后用于清理喷嘴和稳定出料的擦料塔。
6、Prime Tower Center X/Y：擦料塔中心位置。
7、Tower Width、Tower Depth、Infill Density：控制擦料塔尺寸和填充密度。
8、Edit Start G-code 和 Edit End G-code：编辑开始和结束脚本。

## 录制方法

1、用两色字壳案例演示在某个高度换色。
2、开启 Prime Tower 后，在 2D 或 3D 结果中说明它的作用。
3、编辑 Start/End G-code 时只演示入口和用途，不建议新手随意修改复杂脚本。

# 第二十章 Process 处理与切片校验（7 个知识点）

## 学习目标

让用户理解 Process 是生成切片和导出的前置步骤。

## 知识点

1、Process 会根据当前图形和参数生成切片结果。
2、修改图形、工艺参数、起始点或打印顺序后，都应重新 Process。
3、G-code 和 STL 导出依赖 Process 结果。
4、处理前检查图形是否在打印区域内。
5、处理前检查是否选择了正确 Printer Profile。
6、处理前检查互斥工艺是否符合预期，例如底壳、背板槽、灯带槽。
7、处理完成后进入 Preview 检查，不建议直接导出生产。

## 录制方法

1、故意修改一个参数后展示需要重新 Process。
2、展示未处理直接导出时软件会提示需要先处理。
3、强调 Process 是“生成生产路径”的动作，不只是刷新界面。

# 第二十一章 3D Preview 预览检查（7 个知识点）

## 学习目标

让用户学会在导出前检查 3D 结果，减少实际打印失败。

## 知识点

1、Preview 页面用于查看处理后的 3D 结果。
2、首次进入 Preview 时，如果已有图形但没有切片结果，软件会尝试自动处理。
3、3D 视图用于检查字壳高度、边型、槽位、底壳和裙边。
4、层预览用于检查不同高度的打印路径。
5、通过旋转视角检查外壁、内孔和底部结构。
6、发现结构错误时返回 Project 修改参数。
7、修改后重新 Process，再回到 Preview 复查。

## 录制方法

1、生成直边、斜边和带槽位的三个案例进行对比。
2、用带内孔的字母检查内孔墙和底部结构。
3、不要声称未启用的预览工具栏功能已经可用，只讲当前可见和可操作的预览内容。

# 第二十二章 导出 G-code、STL、背板 DXF、亚克力面板 DXF（8 个知识点）

## 学习目标

让用户明确每种导出文件的用途和前置条件。

## 知识点

1、Export G-code：导出给打印机使用的生产代码。
2、Export STL：导出三维模型文件，用于检查、归档或进入其他软件。
3、Export Back Plate DXF：导出背板轮廓，用于激光切割或后续加工。
4、Export Acrylic Face DXF：导出亚克力面板轮廓，用于激光切割或后续加工。
5、Export 按钮支持导出格式选择，并可记住最近使用的主要导出格式。
6、G-code 和 STL 通常需要先 Process。
7、Back Plate DXF 和 Acrylic Face DXF 需要当前项目中有有效轮廓。
8、DXF 导出会受到外轮廓间隙、内孔间隙和激光切缝补偿影响。

## 录制方法

1、同一个项目依次导出 G-code、STL、Back Plate DXF、Acrylic Face DXF。
2、打开导出的文件夹，让用户看到四种文件的命名和用途。
3、导出 DXF 前后修改补偿值，对比轮廓变化。

# 第二十三章 最近项目、配置目录与工作流复用（7 个知识点）

## 学习目标

让用户学会复用项目、复用参数和进行基础售后定位。

## 知识点

1、Recent Projects 用于快速打开最近保存或打开过的 SMP 项目。
2、Open Recent 可打开最近的 DXF、SVG、SMP 文件。
3、项目复用方法：打开旧 SMP，另存为新项目，再替换或调整图形。
4、参数复用方法：保持同一项目参数，导入相似订单图形。
5、Printer Profile 会保存用户的机器设置。
6、Show Configuration Folder 可用于查看本机配置文件位置。
7、售后排查时，建议用户同时提供 SMP 项目、导出的 G-code 和软件版本信息。

## 录制方法

1、录制一个“老订单复制成新订单”的过程。
2、展示 Recent Projects 与 Open Recent 的不同入口。
3、最后打开 About 和配置目录，说明售后需要哪些信息。

# 第二十四章 常见问题与避坑（9 个知识点）

## 学习目标

把用户最容易出错的问题集中讲清楚，减少售后沟通成本。

## 知识点

1、导入后尺寸不对：检查源文件单位和导入后的宽高。
2、图形超出平台：检查 Machine 打印区域和 2D 画布位置。
3、无法导出 G-code：检查是否已经 Process。
4、无法导出 STL：检查是否已经生成有效切片结果。
5、底部结构没有出现：检查 Bottom 模式和互斥选项。
6、螺丝孔无法使用：检查是否启用了适合螺丝孔的底部结构。
7、换色没有按预期发生：检查 Change At Height、Macro Index 和 Start G-code。
8、DXF 亚克力面板或背板尺寸不合适：检查 DXF Export Compensation。
9、打印起点或顺序不理想：使用 Start Point 和 Print Order 后重新 Process。

## 录制方法

1、每个问题用 30 到 60 秒讲一个典型错误。
2、先展示错误现象，再展示修正方法。
3、这一章适合做成售后 FAQ 视频，也可以拆成短视频。

# 第二十五章 高级补充与暂不作为主线的内容（5 个知识点）

## 学习目标

说明哪些内容可以作为进阶补充，哪些功能不建议放在入门主线里讲。

## 知识点

1、Panel Fill、Grid Fill、Baseplate Fill 等填充类功能可作为进阶课程或后续版本课程。
2、复杂自定义边型 DXF 需要单独讲图形规范，不建议放入新手第一套课程。
3、多机型、多喷嘴、多材料参数建议在用户完成基础生产闭环后再讲。
4、G-code 脚本深度定制适合代理商、工程师或售后人员，不适合普通新手用户直接修改。
5、算法原理、轮廓偏移、切片内部逻辑可以作为工程师培训内容，不放入普通海外用户课程。

## 录制方法

1、用“进阶课程预告”的方式讲，不要展开太深。
2、明确告诉用户：入门阶段先掌握导入、参数、Process、Preview、Export。
3、高级内容可以按客户行业和机型定制录制。

# 附录一：推荐录制顺序

1、第一批视频：第一章到第七章，目标是让用户会打开软件、导入文件和操作界面。
2、第二批视频：第八章到第十一章，目标是让用户会整理图形和控制打印路径。
3、第三批视频：第十二章到第十六章，目标是让用户掌握核心字壳工艺。
4、第四批视频：第十七章到第二十二章，目标是让用户完成机器设置、处理、预览和导出。
5、第五批视频：第二十三章到第二十五章，目标是售后复用、问题排查和高级补充。

# 附录二：每章视频建议时长

1、基础界面类章节：3 到 6 分钟。
2、文件管理类章节：4 到 8 分钟。
3、编辑工具类章节：6 到 10 分钟。
4、核心工艺类章节：8 到 15 分钟。
5、导出和排错类章节：6 到 12 分钟。
6、高级补充类章节：5 到 8 分钟。

# 附录三：海外录制话术建议

1、第一次出现中文行业词时，同时说英文含义，例如：字壳可以说为 sign letter shell。
2、不要只说“这里调一下”，要说清楚参数名称、单位和影响。
3、不要只展示成功案例，必须展示至少几个典型错误。
4、导出前反复强调三个检查：尺寸、打印区域、3D Preview。
5、售后视频中尽量使用同一套示例文件和同一套打印机配置，降低学习成本。
