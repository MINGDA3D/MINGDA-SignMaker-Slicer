## 1. 产品概述

### 1.1 产品愿景

打造一款**专业、易用、智能**的发光字切片软件，作为我司3D打印机的配套软件，通过软硬件一体化为客户提供最佳的发光字制造解决方案，超越竞品INC-S的用户体验。

### 1.2 产品定位

```
┌─────────────────────────────────────────────────────────────────────┐
│                        SignMaker Slicer                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   产品类型：发光字专用切片软件                                        │
│   目标市场：广告标识制作行业                                          │
│   配套设备：我司发光字3D打印机系列                                    │
│   核心价值：软硬一体化 + 智能易用 + 现代体验                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 产品目标

| 目标类型 | 具体目标 | 衡量指标 |
|----------|----------|----------|
| **功能目标** | 全面对标INC-S核心功能 | 覆盖144个功能点中的P0+P1（87个） |
| **体验目标** | 学习成本降低50% | 新用户30分钟内完成首次打印 |
| **效率目标** | 提升操作效率30% | 相同任务操作步骤减少 |
| **质量目标** | 打印成功率>95% | 生成的G代码无错误 |
| **商业目标** | 提升设备竞争力 | 软件成为设备销售亮点 |

### 1.4 成功标准

- [ ] P0功能100%实现并通过真机验证
- [ ] 内置3D预览功能上线
- [ ] 智能参数推荐功能上线
- [ ] 客户满意度评分≥4.0/5.0

### 2.2 用户画像详情

#### 用户A：广告字制作工人（主要用户）

| 维度 | 描述 |
|------|------|
| **背景** | 初中/高中学历，从事广告制作1-3年 |
| **技能** | 会基本电脑操作，熟悉打印机操作，不熟悉参数含义 |
| **工作内容** | 按照师傅或老板给的参数进行切片、打印 |
| **痛点** | 参数太多不知道怎么设置，出问题不知道怎么调 |

| **使用频率** | 每天使用，每天处理10-50个字 |

#### 用户B：广告字排版师（专业用户）

| 维度 | 描述 |
|------|------|

| **技能** | 精通CorelDRAW，了解各种发光字工艺 |

| **使用频率** | 每天使用，负责参数调试和问题排查 |

#### 用户C：广告公司老板（决策者）

| 维度 | 描述 |
|------|------|

### 2.3 用户场景

#### 场景1：日常生产（高频）

```
用户：工人小张
场景：收到10个"茶"字的打印任务，要求30cm高度、斜边工艺

操作流程：
1. 打开软件，导入DXF文件
2. 选择"斜边字-30cm"预设模板 ← 智能预设
3. 软件自动推荐参数（壁厚1.2mm、斜边宽度5mm等）
4. 点击"排版"，自动排列到版面
5. 点击"预览"，3D查看效果 ← 内置3D预览
6. 确认无误，点击"输出"生成G代码
7. 发送到打印机开始打印

期望耗时：5分钟内完成
```

#### 场景2：新工艺调试（中频）

```
用户：排版师老王
场景：客户要求做连襟字，需要调试参数

操作流程：
1. 导入带连襟框的DXF文件
2. 切换到"连襟字"工艺模式
3. 设置连襟参数（宽度15mm、高度5mm等）
4. 使用"预览字边类型"查看连襟形状
5. 使用3D预览查看整体效果
6. 微调参数，对比不同配置效果 ← 参数对比功能
7. 确认后保存为新模板
8. 输出G代码，进行试打

期望耗时：15-30分钟
```

#### 场景3：问题排查（低频）

```
用户：排版师老王
场景：打印出来的字壳台阶位置不对

操作流程：
1. 打开之前的项目文件
2. 查看台阶V槽参数设置
3. 使用"预览字边类型"查看台阶位置
4. 发现台阶1位置设置错误（应该是4mm设成了14mm）
5. 修正参数，重新预览确认
6. 重新输出G代码

期望：软件能清晰显示台阶位置，便于问题定位
```

| 原则 | 说明 |
|------|------|
| **简洁** | 隐藏复杂参数，提供高级模式 |
| **专业** | 工业软件风格，深色主题减少眼疲劳 |
| **高效** | 常用功能一键触达，减少操作步骤 |
| **智能** | 参数自动推荐，减少手动输入 |

### 5.3 交互模式

#### 5.3.1 简易模式（默认）

- 显示常用参数（字壳高度、斜边宽度、壁厚、层高）
- 提供工艺预设模板一键应用
- 智能参数推荐按钮

#### 5.3.2 专业模式

- 显示全部参数（对标INC-S）
- 8个参数选项卡（字壳、换色、台阶、防翘、连襟、包边、面板、底板）
- 参数对比功能

### 5.4 关键交互流程

#### 5.4.1 导入-切片-输出（主流程）

```
┌─────┐    ┌─────┐    ┌─────┐    ┌─────┐    ┌─────┐    ┌─────┐
│导入 │───▶│排版 │───▶│设参数│───▶│计算 │───▶│预览 │───▶│输出 │
│DXF │    │布局 │    │     │    │路径 │    │检查 │    │Gcode│
└─────┘    └─────┘    └─────┘    └─────┘    └─────┘    └─────┘
   │          │          │          │          │          │
   ▼          ▼          ▼          ▼          ▼          ▼
自动识别   可选步骤    智能推荐   显示时间   2D/3D     保存文件
颜色标识   可跳过     一键预设   和耗材     可切换    或发送设备
```

## 7. 技术约束

### 7.1 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 开发语言 | Python 3.11+ | 开发效率高，库生态丰富 |
| GUI框架 | PySide6 | Qt官方绑定，跨平台，工业级 |
| 几何算法 | pyclipper | 多边形偏移和布尔运算 |
| DXF解析 | ezdxf | 成熟的DXF处理库 |
| 3D渲染 | OpenGL (PyOpenGL) | 高性能3D预览 |
| 打包 | PyInstaller | 生成独立可执行文件 |

### 7.2 开发约束

| 约束 | 说明 |
|------|------|
| 代码规范 | PEP8，类型注解 |
| 文件大小 | 单文件<500行 |
| 测试覆盖 | 核心算法>80% |
| 文档 | 公共方法必须有docstring |

### 7.3 部署约束

| 约束 | 说明 |
|------|------|
| 安装包大小 | <100MB |
| 依赖 | 无需额外安装运行时 |
| 更新 | 支持在线检查更新 |

## 9. 风险与依赖

### 9.1 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 斜边算法复杂度高 | 开发延期 | 中 | 提前PoC验证 |
| 3D预览性能问题 | 用户体验差 | 中 | 采用LOD优化 |
| DXF兼容性问题 | 部分文件无法导入 | 中 | 收集真实样本测试 |
| G代码兼容性 | 打印异常 | 低 | 与设备团队密切合作 |

### 9.2 资源风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 开发人力不足 | 进度延期 | 中 | 优先保证P0功能 |
| 测试设备不足 | 验证不充分 | 低 | 协调设备资源 |

### 9.3 外部依赖

| 依赖 | 提供方 | 风险 |
|------|--------|------|
| 打印机通信协议 | 设备部门 | 需要协调文档 |
| 测试设备 | 设备部门 | 需要协调时间 |
| 客户反馈 | 销售部门 | 需要建立渠道 |

## 10. 验收标准

### 10.1 功能验收

| 验收项 | 标准 | 验收方法 |
|--------|------|----------|
| DXF导入 | 正确解析100%测试用例 | 自动化测试 |
| 直边生成 | 壁厚误差<0.1mm | 真机打印测量 |
| 斜边生成 | 斜边角度误差<1° | 真机打印测量 |
| G代码 | 100%可执行 | 全量打印验证 |
| 打印时间预估 | 误差<10% | 实际计时对比 |

### 10.2 性能验收

| 验收项 | 标准 | 验收方法 |
|--------|------|----------|
| 启动时间 | <3秒 | 秒表测量 |
| 切片速度 | <10秒/字 | 秒表测量 |
| 内存占用 | <500MB | 任务管理器 |

### 10.3 用户验收

| 验收项 | 标准 | 验收方法 |
|--------|------|----------|
| 首次使用 | 30分钟完成首次打印 | 新用户测试 |
