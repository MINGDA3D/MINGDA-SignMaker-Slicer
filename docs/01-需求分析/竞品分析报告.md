## 1. 概述

### 1.1 文档目的

本文档对发光字切片软件领域的主要竞品进行全面分析，重点对标 **INC-S（真材科技）** 软件，为 SignMaker Slicer 的产品功能规划、技术实现和超越策略提供决策依据。

**产品定位**：SignMaker Slicer 是我司发光字3D打印机的配套专用切片软件，与自有设备深度集成，为客户提供软硬件一体化解决方案。

### 3.3 支持的工艺类型

#### 3.3.1 按字边分类

| 工艺类型 | 描述 | 关键参数 |
|----------|------|----------|
| 直边字 | 垂直边缘，最基础工艺 | 字壳高度、壁厚、层高 |
| 斜边字 | 倾斜边缘，常见于发光字 | 斜边宽度、面板厚度、底板厚度 |
| 异形边字 | 自定义轮廓边缘 | 可添加/删除自定义异形边配置 |

#### 3.3.2 按特殊工艺分类

| 工艺类型 | 描述 | 复杂度 |
|----------|------|--------|
| 无边字 | 无边框的发光字 | ★★☆ |
| 连襟字（直边） | 多字直边连接成整体 | ★★★ |
| 连襟字（斜边） | 多字斜边连接成整体 | ★★★ |
| 连襟字（菱形） | 双面发光连襟字 | ★★★★ |
| 包边字 | 带包边装饰的发光字 | ★★☆ |
| 勾边字 | 带勾边轮廓的发光字 | ★★☆ |
| 超级字 | 特殊效果字 | ★★★ |
| 正扣亚克力字 | 斜边配合亚克力面板 | ★★★ |

#### 3.3.3 按面板工艺分类

| 工艺类型 | 描述 | 应用场景 |
|----------|------|----------|
| 面板打印一体成型字 | 字壳与面板一体打印 | 快速成品 |
| 面板花纹打印字 | 面板带花纹图案 | 装饰效果 |
| 印花字 | 面板带印花效果（直边花纹） | 灌液态亚克力 |

### 3.4 核心参数体系

#### 3.4.1 字壳参数（核心）

| 参数 | 默认值 | 范围/说明 |
|------|--------|-----------|
| 字壳高度 | - | 根据实际需求(mm) |
| 斜边宽度 | 5mm | 直边时无需设置 |
| 面板厚度 | - | 亚克力板实际厚度 |
| 底板厚度 | 10mm | 底部直边高度 |
| 层高 | 0.3mm | 每层打印高度 |
| 壁厚 | 1.2mm(小字)/1.3mm(大字) | 40cm为分界 |
| 壁厚补偿 | 0 | 补偿值 |
| 走线次数 | 1 | 可设2次打印2.4mm |
| 走线偏移 | 0.8mm | 双层粘接间距 |
| 预打边线偏移 | 15-35mm | 安全线距离 |
| 预打边线次数 | 1次 | 面板一体成型设2-4次 |

#### 3.4.2 换色参数

| 参数 | 说明 |
|------|------|
| 层数 | 软件自动计算 |
| 层高 | 每层高度(mm) |
| 挤出机 | 1/2/3号选择 |
| 换色偏移 | 自动偏移到字壳外围 |

#### 3.4.3 台阶参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 台阶数量 | 2个 | 支持1-7个 |
| 台阶位置 | - | 底板厚度+1-2mm预留 |
| 台阶高度 | 1.2mm(V型)/0(平) | V型或平台阶 |
| 台阶宽度 | 1.2mm | 台阶宽度 |
| 台阶厚度 | 0.3mm | 平台阶层厚 |

#### 3.4.4 填充参数

| 类型 | 填充间距 | 边界距离 | 角度 | 填充高度 |
|------|----------|----------|------|----------|
| 面板正面 | 按需设置 | 1.4mm | 45° | 0.6mm |
| 面板背面 | 0.9mm | 1.4mm | 45° | 1.5mm |
| 网格 | 按字大小 | 3.2mm | 45° | 1.2-1.5mm |

### 3.7 技术实现分析

#### 3.7.1 输入输出格式

| 类型 | 格式 | 说明 |
|------|------|------|
| 输入 | DXF (AutoCAD 2004) | 从CDR/AI导出的矢量文件 |

|------|----------------|
| 路径偏移 | Clipper库（多边形偏移） |
| 斜边生成 | 分层偏移+Z轴插值 |
| 台阶V槽 | 特定层偏移+楔形路径 |
| 填充算法 | 直线填充+角度偏移 |
| 路径优化 | TSP近似算法（减少空程） |
| 连襟处理 | 布尔运算（合并/裁剪） |

## 4. 竞品SWOT分析

### 4.1 INC-S 优势 (Strengths)

| 优势 | 具体表现 |
|------|----------|
| **功能全面** | 覆盖发光字全部主流工艺（直边/斜边/异形边/连襟/包边等） |
| **参数丰富** | 144个功能点，支持精细化控制 |
| **工艺成熟** | 多年行业积累，参数默认值经过验证 |
| **设备捆绑** | 与真材科技打印机深度集成 |
| **用户基础** | 广告字行业占有一定市场份额 |
| **教程完善** | 提供视频教程覆盖各类工艺 |

### 4.2 INC-S 劣势 (Weaknesses)

| 劣势 | 具体表现 |
|------|----------|
| **界面老旧** | UI设计停留在传统Windows风格，用户体验差 |
| **学习曲线** | 参数过多，新手难以上手 |
| **无3D预览** | 需要调用外部软件进行3D预览，操作繁琐 |
| **缺乏现代化** | 无云端同步、无自动更新机制 |
| **单一平台** | 仅支持Windows |
| **参数不智能** | 缺乏根据字体大小自动推荐参数的能力 |
| **预设模板少** | 常用工艺预设不够丰富 |

### 4.3 SignMaker Slicer 机会 (Opportunities)

| 机会 | 策略 |
|------|------|
| **现代UI** | 采用现代化界面设计，降低学习成本 |
| **智能参数** | 基于字体大小、工艺类型自动推荐参数 |
| **内置3D预览** | 无需外部软件，实时预览打印效果 |
| **丰富预设** | 提供丰富的工艺参数预设模板 |
| **软硬一体** | 与自有打印机深度集成，优化打印效果 |
| **工艺创新** | 利用软硬件一体优势，探索新工艺 |
| **售后优势** | 软硬件统一售后，问题定位更快 |

### 4.4 SignMaker Slicer 威胁 (Threats)

| 威胁 | 应对 |
|------|------|
| **用户习惯** | 提供INC-S风格兼容模式和参数导入工具 |
| **工艺验证** | 充分利用自有设备进行打印验证 |
| **技术门槛** | 核心算法需要大量研发投入 |
| **市场教育** | 通过软件优势带动设备销售 |

## 8. 结论与建议

### 8.1 核心结论

1. **INC-S是行业标杆**：功能全面、参数丰富、工艺成熟，是我们学习和超越的目标
2. **存在差异化空间**：现代UI、智能参数、内置3D预览、软硬一体等方面有突破机会
3. **软硬一体优势**：作为打印机厂商，我们可以深度优化软硬件配合，提供更好的打印体验
4. **技术门槛可控**：核心算法（偏移、切片、填充）有成熟开源库可用
5. **MVP需聚焦**：先实现直边/斜边核心功能，再逐步扩展高级工艺
