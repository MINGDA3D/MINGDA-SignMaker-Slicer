# SignMaker Slicer 系统架构设计

---

## 1. 概述

### 1.1 文档目的
本文档描述 SignMaker Slicer 发光字切片软件的系统架构设计，包括核心模块、数据流、接口定义和扩展性考虑。

### 1.2 系统定位
SignMaker Slicer 是一款专业的发光字（LED字壳）3D打印切片软件，对标竞品 INC-S，提供从 DXF 导入到 G-code 输出的完整工作流程。

### 1.3 技术栈
| 类别 | 技术选型 | 版本 |
|------|----------|------|
| 语言 | Python | 3.11+ |
| GUI框架 | PySide6 | 6.6+ |
| 几何库 | pyclipper | 1.3+ |
| DXF解析 | ezdxf | 1.1+ |
| 3D渲染 | PyOpenGL + numpy | - |
| 文件格式 | JSON (项目), G-code (输出) | - |

### 3.1 基础类型 (`src/core/types.py`)

```python
from dataclasses import dataclass, field
from enum import Enum, auto
from typing import List, Tuple, Optional, Dict

# ============ 基础几何类型 ============

@dataclass
class Point:
    """2D点坐标"""
    x: float
    y: float

    def __iter__(self):
        yield self.x
        yield self.y

@dataclass
class Point3D:
    """3D点坐标"""
    x: float
    y: float
    z: float


# ============ 路径类型 ============

class PathType(Enum):
    """路径类型"""
    OUTER = auto()      # 外轮廓
    INNER = auto()      # 内轮廓（孔）
    CONNECTED = auto()  # 连襟框
    PATTERN = auto()    # 面板花纹
    HOLE = auto()       # 底孔

@dataclass
class Path:
    """单条路径（闭合多边形）"""
    points: List[Point]
    path_type: PathType = PathType.OUTER
    color: Tuple[int, int, int] = (0, 0, 0)  # RGB颜色
    start_index: int = 0  # 起始点索引

    @property
    def is_closed(self) -> bool:
        """路径是否闭合"""
        return len(self.points) > 2

    @property
    def bounds(self) -> Tuple[float, float, float, float]:
        """返回边界框 (min_x, min_y, max_x, max_y)"""
        xs = [p.x for p in self.points]
        ys = [p.y for p in self.points]
        return min(xs), min(ys), max(xs), max(ys)


# ============ 轮廓类型 ============

@dataclass
class Contour:
    """字形轮廓（包含外轮廓和内孔）"""
    outer: Path                          # 外轮廓
    holes: List[Path] = field(default_factory=list)  # 内孔列表
    connected_frames: List[Path] = field(default_factory=list)  # 连襟框
    patterns: List[Path] = field(default_factory=list)  # 面板花纹

    # 元数据
    name: str = ""                       # 字形名称
    source_file: str = ""                # 来源文件


# ============ 层类型 ============

class ExtruderType(Enum):
    """挤出机类型"""
    EXTRUDER_1 = 1  # 主挤出机（通常是遮光材料）
    EXTRUDER_2 = 2  # 2号挤出机（透光材料）
    EXTRUDER_3 = 3  # 3号挤出机（透光材料）

class PathRole(Enum):
    """路径角色"""
    WALL = auto()           # 字壳壁
    STEP = auto()           # 台阶
    SKIRT = auto()          # 防翘裙边
    FILL_PANEL = auto()     # 面板填充
    FILL_GRID = auto()      # 网格填充
    FILL_BASEPLATE = auto() # 底板填充
    EDGE_WRAP = auto()       # 包边
    EDGE_OUTLINE = auto()   # 勾边
    SAFETY_LINE = auto()    # 预打边线（安全线）

@dataclass
class LayerPath:
    """层内路径"""
    points: List[Point]
    role: PathRole
    extruder: ExtruderType = ExtruderType.EXTRUDER_1
    line_width: float = 1.2  # 线宽 mm
    is_closed: bool = True

@dataclass
class Layer:
    """单个打印层"""
    z_height: float                      # 层高度 (mm)
    layer_height: float                  # 层厚 (mm)
    paths: List[LayerPath] = field(default_factory=list)
    extruder: ExtruderType = ExtruderType.EXTRUDER_1

    # 层级别的速度覆盖（可选）
    print_speed: Optional[float] = None
    travel_speed: Optional[float] = None


# ============ 边缘类型 ============

class EdgeType(Enum):
    """字边类型"""
    STRAIGHT = auto()  # 直边
    BEVELED = auto()   # 斜边
    CUSTOM = auto()     # 异形边

@dataclass
class EdgeProfile:

    name: str
    points: List[Point]  # 归一化的边缘轮廓点 (0-1范围)


# ============ 切片参数 ============

@dataclass
class ShellParams:
    """字壳参数"""
    height: float = 30.0           # 字壳总高度 (mm)

    # 斜边参数

    panel_thickness: float = 3.0   # 面板厚度 (mm)

    # 壁厚参数

    # 字芯参数
```

### 4.2 路径偏移器 (`src/core/path_offset.py`)

**职责**：使用pyclipper进行路径的内/外偏移

```python
class PathOffset:
    """路径偏移处理器"""

    SCALE = 1000  # pyclipper使用整数，需要缩放

    def offset(self, path: Path, distance: float,
               join_type: JoinType = JoinType.MITER) -> List[Path]:
        """
        对路径进行偏移

        Args:
            path: 输入路径
            distance: 偏移距离（正=外扩，负=内缩）
            join_type: 拐角处理方式 (MITER/ROUND/SQUARE)

        Returns:
            偏移后的路径列表（可能产生多个路径）
        """
        pass
```

**斜边计算公式**：
```
offset = 0                                          (z <= baseplate_thickness)
offset = (z - baseplate) / bevel_width * max_offset (baseplate < z < baseplate + bevel)
offset = max_offset                                 (z >= baseplate + bevel_width)

其中 max_offset = bevel_width（斜边宽度）
```
