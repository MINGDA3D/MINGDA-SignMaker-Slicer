# MINGDA SignMaker 功能总结

**MINGDA SignMaker** 是一款专为发光字3D打印设计的切片软件，支持生成字壳 G-code 和 STL 模型。

---

## 📁 文件操作

| 功能 | 说明 |
|------|------|
| DXF 导入 | 支持 LWPOLYLINE、POLYLINE、LINE、ARC、CIRCLE、ELLIPSE 等实体 |
| SVG 导入 | 支持 transform 属性、单位转换、Y轴镜像 |
| STL 导出 | 导出三维模型，支持包边和勾边效果（已替代 G-code 成为主导出格式） |
| DXF 导出 | 支持导出底板/面板轮廓为 DXF 文件 |
| 项目保存/加载 | `.smp` 格式（ZIP 容器 + JSON 参数 + 二进制几何数据） |

---

## 🔧 字壳工艺

| 功能 | 说明 |
|------|------|
| 直边模式 | 标准垂直边字壳 |
| 斜边模式 | 上小下大 / 上大下小，可自定义宽度和角度 |
| 异形边 | 自定义边缘轮廓，内置多种预设样式，U 形字轮廓通过 Custom 预设模板提供 |
| 卡槽功能 | 亚克力面板卡槽 + 背板卡槽，高度随字壳联动 |
| 防翘裙边 | 连续梯形链结构，支持内孔裙边，v2 算法拐角绕行 + 跨轮廓裁剪 |
| 连襟字 | MST 算法自动连接离散轮廓，支持多内孔连接 |
| 包边 | STL 导出时的包边效果 |
| 勾边 | 斜坡边效果，平滑分层 |
| 底面封闭 | G-code 和 STL 导出均支持 |
| 顶面封闭 | G-code 和 STL 导出均支持，含 UI 参数设置 |

---

## 🖥️ 用户界面

| 功能 | 说明 |
|------|------|
| 2D 画布预览 | 实时矢量图形显示，带标尺和平台 |
| 3D 预览 | OpenGL 渲染（完善中） |
| 参数面板 | 完整的字壳工艺参数设置 |
| 撤销/重做 | 完整操作历史记录 |
| 自动居中 | 导入时自动居中到平台中心 |
| 变换浮动面板 | 移动、旋转、缩放、镜像操作 |
| 缩放面板 | Size/Scale 双模式 + Uniform Scale（参考 OrcaSlicer） |
| 旋转面板 | 角度输入框，参考 OrcaSlicer Gizmo 交互 |
| 右键菜单 | 画布右键拖动平移 + 上下文菜单 |
| 首页 | 最近项目列表 + 快速入口 |
| 自定义标题栏 | 优化布局和功能 |
| 图形列表面板 | 管理导入的图形对象 |
| +/- 数值控件 | 左右布局增减输入组件 |

|------|------|
