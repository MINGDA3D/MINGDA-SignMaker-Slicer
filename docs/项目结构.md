## 模块说明

### 核心层 (src/core/)

| 模块 | 职责 |
|------|------|
| `types.py` | 定义所有数据类型：Point, Path, Contour, Layer, SliceParams等 |
| `dxf_parser.py` | 解析DXF文件，提取轮廓和颜色信息 |
| `path_offset.py` | 使用pyclipper进行路径偏移和布尔运算 |
| `slice_engine.py` | 核心切片逻辑，协调各生成器 |
| `gcode_writer.py` | 将层数据转换为G-code指令 |
| `bevel_generator.py` | 生成直边、斜边、异形边轮廓 |
| `step_generator.py` | 生成台阶和V槽结构 |
| `fill_generator.py` | 生成面板、网格、底板填充 |
| `skirt_generator.py` | 生成V型防翘裙边 |
| `connected_generator.py` | 生成连襟字结构 |

### 业务层 (src/business/)

| 模块 | 职责 |
|------|------|
| `slice_manager.py` | 异步切片任务管理，协调解析、切片、导出 |
| `project_manager.py` | 项目CRUD操作，.dada格式读写 |
| `preset_manager.py` | 预设模板管理，加载/保存/删除 |

### 表现层 (src/ui/)

| 模块 | 职责 |
|------|------|
| `main_window.py` | 主窗口框架，菜单栏，工具栏 |
| `canvas_2d.py` | 2D画布，轮廓显示，交互编辑 |
| `param_panel.py` | 参数面板容器（选项卡组织） |
| `project_panel.py` | 项目树，文件管理 |
| `theme.py` | 深蓝科技风格Qt样式表 |
| `panels/*.py` | 各功能参数面板组件 |

### 参数面板 (src/ui/panels/)

| 面板 | 功能 |
|------|------|
| `shell_panel.py` | 字壳高度、壁厚、边缘类型 |
| `color_panel.py` | 换色层配置、多挤出机 |
| `step_panel.py` | 台阶位置、高度、宽度 |
| `skirt_panel.py` | 防翘裙边参数 |
| `connected_panel.py` | 连襟字类型和尺寸 |
| `edge_wrap_panel.py` | 包边勾边参数 |
| `panel_fill_panel.py` | 面板/网格/底板填充 |
| `export_panel.py` | 输出参数、温度、速度 |
| `speed_panel.py` | 详细速度设置 |
| `machine_panel.py` | 机器类型、版面尺寸 |

## 数据流

```
DXF文件 → DXFParser → List[Contour] → Canvas2D (显示)
                            ↓
参数面板 → SliceParams → SliceEngine → SliceResult → Preview3D
                                            ↓
                                      GCodeWriter → .gcode文件
```
